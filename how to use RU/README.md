# Рюкзаки — как пользоваться

Рюкзак — носимый предмет с собственным инвентарём. Он надевается на игрока, открывается
клавишей и улучшается крафтом, не теряя содержимое. Всего 17 тиров: от «Льняного мешочка»
на 9 ячеек до «Абсолютного рюкзака» на 256 ячеек.

- Английская версия: [How to use — English](../how%20to%20use%20EN/README.md)
- Краткое описание и таблица тиров: [README.md](../README.md)
- Скачать файлы: [Releases](https://github.com/MrLan112/Backpacks-Plugin-Mod/releases)

---

## 1. Что нужно

| Часть | Версия |
| --- | --- |
| Сервер | Purpur или Paper **26.3** |
| Java | **25** |
| Клиентский мод (необязательно) | Fabric Loader **0.20.1+**, Fabric API **0.166.2+26.3**, Minecraft **26.3** |

Плагин работает и без мода: рюкзаки открываются, надеваются и крафтятся. Мод добавляет
3D-модель рюкзака на спине, отдельный слот в инвентаре и свою клавишу открытия.

## 2. Установка

### Сервер (админ)

1. Положите `Backpacks-1.0.0.jar` в папку `plugins/`.
2. Запустите сервер. При первом запуске создадутся:
   - `plugins/Backpacks/config.yml` — настройки;
   - `plugins/Backpacks/messages.yml` — тексты RU/EN;
   - `plugins/Backpacks/backpacks.db` — база содержимого рюкзаков.
3. Выдайте первый рюкзак: `/bp give <игрок> 1`.

### Клиент (для 3D-модели и слота)

1. Установите Fabric Loader 0.20.1+ для Minecraft 26.3 и Fabric API.
2. Положите `backpacks-mod-1.0.0.jar` в папку `mods/`.
3. Запустите игру и зайдите на сервер.

Мод — только клиентская часть: без плагина на сервере он ничего не делает.

## 3. Первые шаги

1. **Получите рюкзак.** Попросите админа (`/bp give <ник> 1`) или скрафтите
   «Льняной мешочек»: 5 нитей + 2 кожи в любом порядке в сетке 3×3.
2. **Наденьте его.** ПКМ по рюкзаку в своём инвентаре, либо Shift+ПКМ рюкзаком в руке,
   либо `/bp equip`. С модом — ЛКМ по слоту рюкзака в инвентаре выживания.
3. **Откройте.** С модом нажмите клавишу открытия (по умолчанию **B**), без мода — **F**
   или ПКМ пустой рукой. Также работает `/bp`, ПКМ рюкзаком в руке и ПКМ по слоту рюкзака.
4. **Сложите вещи** и закройте GUI (E). Содержимое сохранится автоматически.
5. **Улучшайте** рюкзак крафтом — вещи внутри останутся на месте.

## 4. Управление

| Действие | Без мода | С модом |
| --- | --- | --- |
| Открыть надетый рюкзак | **F**, ПКМ пустой рукой, `/bp` | Клавиша открытия (по умолчанию **B**), `F`, `/bp`, ПКМ по слоту рюкзака |
| Открыть рюкзак в руке | ПКМ рюкзаком в руке | ПКМ рюкзаком в руке |
| Надеть | ПКМ по рюкзаку в своём инвентаре, Shift+ПКМ в руке, `/bp equip` | ЛКМ по слоту рюкзака |
| Снять | **Shift+F**, Shift+ПКМ пустой рукой, `/bp unequip` | **Shift+клавиша открытия**, ЛКМ по слоту рюкзака |
| Заменить на другой | Shift+ПКМ другим рюкзаком в руке | Shift+ПКМ другим рюкзаком в руке |

Клавишу открытия можно переназначить: **Настройки → Управление → Рюкзаки**
(`key.backpacks.open`). Лор предмета и сообщения всегда показывают реально
назначенную клавишу.

Ограничения: рюкзак нельзя положить в рамку и «надеть» на лошадь, а ПКМ рюкзаком
по музыкальному блоку открывает рюкзак, а не проигрывает пластинку.

## 5. Окно рюкзака

- Вместимость указана в **ячейках**. В ячейку помещается один стак предмета, а с 9-го
  тира — до **27 стаков** одного и того же предмета.
- Если ячеек больше 45, окно листается стрелками внизу: «Предыдущая страница» и
  «Следующая страница».
- Обычные тиры (1–8) работают как сундук: ЛКМ — взять/положить стак, Shift+ЛКМ —
  быстро переместить.
- Ячейки-стаки (тиры 9–17):
  - **ЛКМ** — взять/положить целый стак;
  - **ПКМ** — взять/положить 1 предмет;
  - **Shift+ЛКМ** — забрать всё из ячейки;
  - **Shift+ЛКМ по предмету в своём инвентаре** — разложить его по подходящим
    ячейкам текущей страницы.
- Рюкзак нельзя положить внутрь другого рюкзака.
- В GUI есть подсказки: количество предметов и стаков в ячейке, номер страницы,
  подсказка по кликам.

## 6. Крафт и улучшение

Все рецепты **бесформенные**: материалы и рюкзак предыдущего тира можно класть в любом
порядке в сетку 3×3. Лишние материалы того же типа остаются в сетке.

- Первый тир крафтится с нуля.
- Каждый следующий тир требует **рюкзак предыдущего тира** + материалы.
- При улучшении содержимое и UUID хранилища сохраняются: вещи остаются внутри,
  меняется только тир и вместимость.
- Посмотреть все 17 рецептов в игре: `/bp recipes` (или книга рецептов — рецепты там
  тоже есть).

Примеры:

| Тир | Что крафтить |
| --- | --- |
| 1. Льняной мешочек | 5 нитей + 2 кожи |
| 2. Кожаный ранец | Льняной мешочек + 4 кожи + 2 нити |
| 3. Медный рюкзак | Кожаный ранец + 6 медных слитков + 2 кожи |
| … | … |
| 17. Абсолютный рюкзак | Драконий рюкзак + 2 звезды Незера + 2 кристалла Края + 2 незеритовых слитка + 1 драконье дыхание + 1 эндер-жемчуг |

Полная таблица тиров и материалов: [README.md → Tiers](../README.md#tiers).

## 7. Команды и права

| Команда | Право | Что делает |
| --- | --- | --- |
| `/bp` | `backpacks.use` | Открыть надетый или находящийся в руке рюкзак |
| `/bp recipes` | `backpacks.use` | Показать все 17 рецептов |
| `/bp equip` | `backpacks.use` | Надеть рюкзак из руки |
| `/bp unequip` | `backpacks.use` | Снять рюкзак |
| `/bp give <игрок> <тир> [кол-во]` | `backpacks.admin` | Выдать рюкзак (тир 1–17 или id) |
| `/bp remove` | `backpacks.admin` | Удалить рюкзак из руки вместе с содержимым |
| `/bp reload` | `backpacks.admin` | Перезагрузить конфиг и тексты |

Псевдонимы: `/backpack`, `/bp`, `/rukzak`, `/рюкзак`.

| Право | По умолчанию | Описание |
| --- | --- | --- |
| `backpacks.use` | все | Пользоваться рюкзаками |
| `backpacks.admin` | OP | Выдавать, удалять, перезагружать |
| `backpacks.modbypass` | OP | Заходить без мода при `require-mod: true` |

## 8. Настройки (`config.yml`)

```yaml
language: ru            # ru или en

equipment:
  keep-on-death: true   # оставлять надетый рюкзак после смерти

storage:
  file: backpacks.db

hotkey: SWAP_HANDS      # F без мода; NONE — выключить
open-empty-hand: true   # ПКМ пустой рукой открывает надетый рюкзак
require-mod: false      # кикать игроков без клиентского мода

gui:
  filler: GRAY_STAINED_GLASS_PANE
  sound-open: BLOCK_CHEST_OPEN
  sound-close: BLOCK_CHEST_CLOSE
  sound-click: UI_BUTTON_CLICK
  sound-upgrade: BLOCK_ANVIL_USE

autosave-seconds: 30    # 0 — сохранять только при закрытии
```

Тексты и лор предметов лежат в `messages.yml` (секции `ru` и `en`). У файла есть
`messages-version`: устаревший файл сохраняется как `messages.yml.<время>.bak`
и заменяется новым, поэтому новые ключи не пропадают.

## 9. Сохранность содержимого

Вещи хранятся **не в предмете**, а в `plugins/Backpacks/backpacks.db` (SQLite), ключ —
UUID в предмете. Предмет носит только тир и UUID, поэтому улучшение тира вещи не теряет.

- Сохранение: через 1 секунду после последнего клика в GUI, при закрытии, при выходе
  игрока, каждые 30 секунд и синхронно при остановке сервера.
- Открытие ждёт завершения очереди записи — «закрыл и сразу открыл» ничего не откатывает.
- Если база недоступна или данные не читаются, рюкзак **не откроется**: иначе закрытие
  пустого окна перезаписало бы реальное содержимое.
- Один рюкзак нельзя открыть двум игрокам одновременно (защита от копий предмета).
- SQLite работает в режиме WAL с `synchronous=FULL`: подтверждённые записи переживают
  сбой питания. При жёстком сбое сервера теряется максимум ~1 секунда изменений после
  последнего клика.

**Периодически делайте резервную копию `backpacks.db`** — лучше на остановленном
сервере; на живом копируйте вместе с `backpacks.db-wal` и `backpacks.db-shm`.

Что может уничтожить сам **предмет** (содержимое останется в базе, но вернуть его
без предмета нельзя): лава, огонь, пустота, кактус, `/clear`, плагины очистки,
`/bp remove`, смерть в лаве/пустоте при `keep-on-death: false`.

## 10. Частые вопросы

**Рюкзак не открывается, пишет «Ошибка базы данных».**
Файл `backpacks.db` недоступен или повреждён. Проверьте права на папку
`plugins/Backpacks`, место на диске и логи сервера. Плагин специально не открывает
пустое окно, чтобы не потерять вещи.

**«Этот рюкзак уже открыт другим игроком».**
Одно хранилище нельзя редактировать одновременно. Закройте рюкзак у второго игрока
(или это копия предмета через креатив — используйте один экземпляр).

**«Нет места в инвентаре — рюкзак остался надет».**
Освободите слот и повторите снятие. Рюкзак никогда не выбрасывается на землю при
снятии.

**Не видно 3D-модели / нет слота в инвентаре.**
Не установлен клиентский мод или Fabric API. Без мода рюкзак выглядит как обычный
предмет, но полностью работает.

**Клавиша не открывает рюкзак.**
Проверьте привязку в **Настройки → Управление → Рюкзаки**. Без мода используется `F`
(если `hotkey: SWAP_HANDS`), и рюкзак должен быть надет.

**Куда делись вещи после улучшения?**
Они внутри: улучшение меняет только тир и вместимость. Откройте рюкзак и проверьте
следующие страницы.

**Как перенести рюкзак на другой сервер?**
Переносите `backpacks.db` вместе с предметами (или выдавайте новые). Содержимое
привязано к UUID в базе, а не к нику игрока.
